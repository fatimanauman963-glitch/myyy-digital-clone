# How I work and study

## My rhythm
I am a night owl, so my best focus time is late in the evening and at night, when it is quiet. I avoid planning important work early in the morning because I am not at my best then.

## Breaks
When I need a break from coding or studying, I switch to art related things like painting. It helps me reset and then I can come back to the code with a fresh mind.

## Learning style
I learn software by building real projects, like the QR Attendance System and my digital clone chatbot, instead of only reading theory. When something breaks, for example an API error, I read the error message carefully and try another solution, like switching to a different LLM provider.

## Advice I would give a junior student
- Start with a small working version, then improve it step by step.
- Split a big file into smaller files when it grows, so the project stays easy to understand.
- Never put API keys in your code. Keep them in secrets.
